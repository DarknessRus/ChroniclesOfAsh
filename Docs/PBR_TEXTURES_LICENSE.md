# PBR texture sources

The build downloads these seamless 1K texture maps from Poly Haven into Unity Resources before building the APK:

- Grass Ground: https://polyhaven.com/a/grass_ground
- Rock Ground 02: https://polyhaven.com/a/rock_ground_02

Both texture sets are released under CC0 1.0 Universal. The build packages local copies of the maps, so the installed game does not need an internet connection to render them. Maps are used as base colour, DirectX tangent-space normal, roughness, and rock displacement data.
