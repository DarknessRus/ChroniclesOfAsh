# Хроники Пепла

Отдельный RPG-проект для Android. Игровой движок — **Unity**; сюжетный ИИ хранится отдельно в `ai-server/`.

## Unity
- Исходники игры: `Unity/`.
- APK собирается через GitHub Actions: **Build Unity Android APK**.
- Сборка требует настроенные Unity secrets в настройках репозитория.

## ИИ
- Сервер сюжетного ИИ: `ai-server/`.
- Конфигурация размещения на Render: `render.yaml`.
- Сервер создаёт сюжетные задания и события мира через выбранного AI-провайдера.
- Для работы нужны переменные окружения `AI_API_KEY` и `AI_MODEL`.
- Подключение сервера к Unity требует отдельной интеграции; сервер не встроен в APK.

Разработка игры ведётся только в Unity. Сервер ИИ остаётся отдельным компонентом проекта.
