# Хроники Пепла

Отдельный проект RPG для Android на Godot 4.3. Проект не связан с репозиториями «ШашлычОК».

## Прототип
- Стилизованный 3D-мир с камерой сверху.
- Персонаж, слизень, атака, здоровье, опыт и уровни.
- Процедурно расставленные деревья.
- Панель сюжетных событий: локальные задания при отсутствии сети и подключение к ИИ-соавтору через сервер.
- Завершение задания на победу над слизнем, награда опытом и повторное появление противника.

## ИИ-соавтор
- scripts/ai_story.gd — интерфейс заданий, история событий, локальный резервный режим и запросы к серверу.
- ai-server/server.js — серверная прослойка. Ключ провайдера хранится только в переменных окружения сервера, не в APK.
- render.yaml — шаблон развёртывания сервера на Render.
- Настройка ai/story_endpoint в project.godot должна содержать адрес https://.../api/story после развёртывания сервера.

Сервер ожидает переменные окружения AI_API_KEY и AI_MODEL; AI_API_URL по умолчанию указывает на совместимый с OpenAI API endpoint OpenRouter. Не добавляйте секретный ключ в репозиторий или APK.

ИИ предлагает текст задания и один из ограниченного списка типов цели. Игровая логика проверяет ответы и начисляет награды; ИИ не может напрямую менять состояние игры.

## Управление
На клавиатуре: WASD или стрелки для движения, пробел для атаки. На экране есть сенсорные кнопки движения и атаки.

## Статус
Интеграция ИИ-соавтора добавлена в исходники. Для живой генерации необходимы развёрнутый сервер и API-ключ провайдера. Пока endpoint не настроен, интерфейс использует локальные сюжетные события. APK требуется собрать и проверить на устройстве.
