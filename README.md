# Хроники Пепла

Отдельный проект RPG для Android. Основной и единственный игровой движок проекта — **Unity 6.6**. Проект не связан с репозиториями «ШашлычОК».

## Unity-проект
- Исходники игры находятся в каталоге `Unity/`.
- Android APK собирается workflow **Build Unity Android APK** в GitHub Actions.
- Мир и детали персонажей дополняются процедурными 3D-объектами и материалами; визуальные изменения необходимо проверять на Android-устройстве.
- После каждой сборки проверяйте запуск игры, переход с экрана выбора персонажа, сенсорное управление и производительность.

## Сборка APK
1. Открой вкладку **Actions** репозитория.
2. Выбери **Build Unity Android APK**.
3. Открой успешный запуск и скачай артефакт APK.
4. Установи APK на Android и проверь запуск и управление.

## Сервер ИИ (необязательный)
Каталог `ai-server/` и `render.yaml` сохранены отдельно как серверная заготовка. Они не являются частью игрового проекта Unity и не нужны для базового запуска APK. Для подключения сервера к игре потребуется отдельная проверенная интеграция.

## Важно
Старый проект Godot и его исходники удалены из активной ветки. Дальнейшая разработка ведётся только в `Unity/`.
