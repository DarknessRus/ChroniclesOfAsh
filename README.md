# Хроники Пепла

Отдельный проект одиночной офлайн RPG для Android на Godot 4. Проект не связан с репозиториями «ШашлычОК».

## Текущий прототип
- Стилизованный 3D-мир с камерой сверху.
- Персонаж и слизень-противник.
- Простая атака, здоровье врага, опыт и уровни.
- Процедурно расставленные деревья.

## Файлы
- `project.godot` — настройки проекта.
- `scenes/world.tscn` — игровая сцена и интерфейс.
- `scripts/player.gd` — игрок.
- `scripts/enemy.gd` — противник.
- `scripts/world.gd` — мир и интерфейс.

## Управление
На клавиатуре: WASD или стрелки для движения, пробел для атаки. На экране есть кнопка атаки. Сенсорное движение для телефона ещё предстоит добавить.

## Статус
Это ранний прототип, не готовая игра и не проверенный APK. Сборку и запуск в движке нужно проверить отдельно.
