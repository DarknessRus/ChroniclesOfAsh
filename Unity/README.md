# Хроники Пепла — Unity

Отдельная Unity-версия RPG для Android.

## Визуальная цель
Ориентир: сохранённые в библиотеке изображения «Хроники Пепла: Выбор героя и путь героя» и «Путь героя». Палитра — угольный графит, сталь, приглушённый сине-зелёный туман и янтарно-золотые акценты. Стартовый экран — четыре героя и крупная кнопка начала; игровой мир — горная долина, хвойный лес, река и мост, далёкий готический замок, костёр и мобильный HUD.

## Первый запуск
1. Открой папку `Unity/` в Unity Hub с поддерживаемой версией Unity.
2. Проверь установку Android Build Support, SDK/NDK и OpenJDK.
3. `AshBootstrap.cs` создаёт стартовое меню и игровой мир во время запуска.

## Android CI
Workflow `.github/workflows/build-unity-android.yml` требует настроенные GitHub Actions secrets `UNITY_LICENSE`, `UNITY_EMAIL`, `UNITY_PASSWORD`. Без корректной лицензии Unity runner не сможет экспортировать APK.

Промежуточный статус: стартовый экран выбора героя, процедурный прототип долины, камера слежения, клавиатурное и сенсорное перемещение, кнопки атаки и тестовый противник с уменьшаемым здоровьем. Окружение и герой пока создаются процедурно — это не финальная графика из референса. Реальные бесплатные модели и анимации подключаются отдельным этапом после проверки совместимости и импорта в Unity.
