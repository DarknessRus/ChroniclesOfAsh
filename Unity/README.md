# Хроники Пепла — Unity edition

Отдельная Unity-версия игры. Исходный проект Godot в корне репозитория не изменяется.

## Визуальная цель
Ориентир: сохранённые в библиотеке изображения «Хроники Пепла: Выбор героя и путь героя» и «Путь героя». Палитра — угольный графит, сталь, приглушённый сине-зелёный туман и янтарно-золотые акценты. Верхний экран — четыре героя и крупная кнопка начала; игровой мир — горная долина, хвойный лес, река и мост, далёкий готический замок, костёр и мобильный HUD.

## Первый запуск
1. Создай проект в Unity Hub (Unity 2022.3 LTS или Unity 6 LTS, 3D Core).
2. Скопируй папку `Unity/Assets` в новый проект Unity.
3. Открой любую сцену. `AshBootstrap.cs` автоматически создаст стартовое меню и игровой мир во время запуска.
4. Для Android установи Android Build Support, SDK/NDK и OpenJDK в Unity Hub.

## Android CI
Workflow `.github/workflows/build-unity-android.yml` требует настроенные GitHub Actions secrets `UNITY_LICENSE`, `UNITY_EMAIL`, `UNITY_PASSWORD`. Без лицензии Unity runner не сможет экспортировать APK. В репозитории оставлена исходная Godot-версия как безопасная копия.

Пока это стартовый Unity-порт: базовый экран выбора героя, атмосферный прототип мира и мобильные элементы управления. Модели/анимации высокого качества будут подключаться отдельными бесплатными пакетами с проверкой лицензии.
